Переваги електрокарта

  • Пульт керування для батьків — повний контроль швидкості та напрямку. Ідеально для малюків від 3 років
  • Потужний акумулятор забезпечує тривале катання — дитина отримує максимум задоволення на одному заряді
  • Компактні розміри 85×56×51 см — підходить для квартири, двору, парку. Легко складається для зберігання
  • Безпечна швидкість 10 км/год — достатньо для адреналіну, але безпечно для дитини
  • Витримує до 50 кг — підходить для дітей від 3 до 12 років, довгострокова інвестиція
  • Яскравий червоний або синій дизайн — дитина відразу закохується. Виглядає як справжній гоночний болід

Часті запитання

Якого віку підходить електрокарт? +
Електрокарт Bambi розрахований на дітей від 3 до 12 років та навантаження до 50 кг. Для малюків від 3 років рекомендуємо використовувати пульт керування батьків.
Скільки тримає заряд акумулятора? +
При стандартному режимі використання заряду вистачає на 1–2 години активного катання. Час заряджання близько 8–12 годин від стандартної розетки 220В.
Чи можна використовувати на вулиці? +
Так! Електрокарт чудово їздить по рівному асфальту, плитці, у дворі та в приміщенні. Уникайте їзди по мокрій поверхні та не залишайте під дощем.
Як відбувається доставка і оплата? +
Відправляємо Новою Поштою та Укрпоштою по всій Україні. Оплата виключно при отриманні на відділенні — ви нічого не платите наперед. Термін доставки 1–3 робочих дні.
Що якщо товар пошкоджений або не працює? +
Гарантія 14 днів. Якщо прийшло пошкодження при доставці — одразу зафіксуйте фото на відділенні. Ми вирішимо питання повернення або обміну без зайвих проблем.
